# 🛡️ StealthGuard — Transparent Windows 11 Explorer Interceptor & Decoy (Portable)

**StealthGuard** — портативное десктопное приложение для Windows 11 для прозрачного перехвата, блокировки и подмены (перенаправления) попыток пользователя открыть определенные папки и файлы через интерфейс Проводника (`explorer.exe`), без изменения прав доступа NTFS (ACL), без шифрования и без влияния на службы Windows.

---

## 📦 Портативная версия (Portable)

Приложение полностью автономно и собрано в папку:
`dist\StealthGuard\`

- **Не требует установки Python**, библиотек или прав администратора.
- Можно переносить на флешке или запускать из любой папки.
- Все настройки и правила сохраняются в локальный `config.json` рядом с исполняемым файлом.

---

## 🚀 Способы запуска

В корне проекта и внутри папки `dist\StealthGuard\` находятся файлы запуска:

1. **Обычный запуск (`run.bat` или запуск `StealthGuard.exe`):**
   - Открывает главное окно Fluent Design с эффектом слюды (Mica) и тёмной темой.

2. **Скрытый запуск в фоне (`run_stealth.bat` или `StealthGuard.exe --stealth`):**
   - Запускается напрямую в скрытом фоновом режиме.
   - Защита Проводника начинает работать мгновенно.
   - Появляется всплывающее уведомление Windows и иконка в трее (можно отключить в настройках для 100% невидимости).
   - Для вызова окна нажмите сочетание клавиш:
     `Ctrl + Shift + Alt + L`

---

## ⌨️ Горячая клавиша и раскладка клавиатуры

Вызов окна по `Ctrl + Shift + Alt + L` реализован через WinAPI `RegisterHotKey` по физическому виртуальному коду клавиши (`VK_L = 0x4C`):
- Работает стабильно **независимо от текущей раскладки** Windows (как на английской `EN`, так и на русской `RU` / клавиша `Д`).
- Окно гарантированно выводится на передний план поверх всех приложений (`SetForegroundWindow`).

## ⚙️ Структура портативной сборки (`dist\StealthGuard`)

```text
dist/StealthGuard/
├── StealthGuard.exe          # Автономный исполняемый файл
├── config.json               # Файл правил и настроек
├── run.bat                   # Обычный запуск
├── run_stealth.bat           # Скрытый запуск в фоне
└── _internal/                # Зависимости, Qt6 DLLs, стили Mica и компоненты
```
