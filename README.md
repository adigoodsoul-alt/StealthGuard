## 📌 О проекте

**StealthGuard** — это инструмент пользовательского уровня (User-Mode) для Windows 11, обеспечивающий прозрачный перехват графической навигации в Проводнике (`explorer.exe`), мгновенную подмену на изолированные папки-приманки или виртуальные диски, бесшумное скрытие и блокировку доступа к конфиденциальным каталогам.

При этом **файловая система NTFS, фоновые службы, консоли, IDE, компиляторы, игры и рабочие программы сохраняют 100% прямой доступ к файлам** по их физическим путям. Перехватывается только графическое открытие и поиск пользователя в Проводнике Windows 11.

## 🚀 Быстрый старт (Портативная версия)

1. **Скачайте готовый архив** по кнопке выше или со страницы [Релизов](https://github.com/adigoodsoul-alt/StealthGuard/releases/latest).
2. **Распакуйте архив** в любую удобную папку на локальном диске или на USB-флешке.
3. **Запустите приложение:**
   - `StealthGuard.exe` или `run.bat` — запуск главного окна в стильном Fluent Design (тёмная тема, эффекты Mica).
   - `run_stealth.bat` или `StealthGuard.exe --stealth` — скрытый запуск напрямую в фоне.
4. **Горячие клавиши:**
   - `Ctrl + Shift + Alt + L` — показать / скрыть главное окно из любого места системы.
   - `Ctrl + Shift + Alt + P` — быстрая пауза / возобновление всей защиты за долю секунды.

## ✨ Ключевые возможности

### 1. Три режима защиты папок
- 🔄 **Подмена (Decoy):** мгновенное бесшовное перенаправление в изолированную папку-приманку или сгенерированный визуальный клон (на основе омоглифов), без мигания панели задач.
- 👻 **Скрытие (Hide):** целевая папка удерживается полностью невидимой в Проводнике; при попытке перехода перехватчик тихо возвращает пользователя назад без всплывающих окон.
- ⛔ **Блокировка (Block):** вывод правдоподобного системного окна ошибки Windows 11 и возврат назад.

### 2. Защита от поиска Windows 11 (`search-ms:`) и Everything
- Мониторинг протокола `search-ms:` Проводника: поиск по корню диска или имени скрытого файла мгновенно перехватывается.
- Автоматическая интеграция с популярной утилитой **Everything**: выставление флагов `exclude_hidden` и `exclude_system` при активной защите с тихим перезапуском клиента.

### 3. Технология Total Cloaking и сохранение системных атрибутов
- Системные атрибуты `System + Hidden + NotContentIndexed` накладываются на файлы и целевую директорию на глубину до 12 уровней.
- **Интеллектуальное сохранение атрибутов (`system_attributes_cache.json`):** файлы, которые изначально были системными (`desktop.ini`, `thumbs.db`, системные драйверы), фиксируются в кэше и **не раскрываются** при снятии защиты или паузе.

### 4. Скрытие локальных дисков и виртуальные тома-приманки
- Наложение реестровой маски `NoDrives`.
- Мгновенное удаление узла диска из левой панели навигации XAML Проводника через нативный `SHChangeNotify(SHCNE_DRIVEREMOVED)` без перезапуска `explorer.exe`.
- Монтирование изолированных виртуальных дисков-приманок через Win32 API `DefineDosDeviceW` (корректная обработка перехода «Вверх» по `Alt+Up`).

### 5. Безопасность и защита настроек
- **PBKDF2-HMAC-SHA256 (600 000 итераций)** для защиты настроек мастер-PIN кодом.
- **Обязательная проверка PIN при холодном старте:** при принудительном завершении процесса через Диспетчер задач (`taskkill`), следующее открытие приложения требует ввода PIN до появления главного окна.
- Автоматическая очистка ярлыков из `%APPDATA%\Microsoft\Windows\Recent`.

## ⌨️ Управление горячими клавишами

Хоткеи реализованы через нативный Win32 API `RegisterHotKey` в выделенном цикле сообщений:
- Работают поверх любых полноэкранных окон и игр.
- **Полная независимость от раскладки клавиатуры** (срабатывают одинаково на русской `RU` и английской `EN` раскладках).

| Комбинация | Действие |
|------------|----------|
| `Ctrl + Shift + Alt + L` | Показать / скрыть главное окно StealthGuard |
| `Ctrl + Shift + Alt + P` | Глобальная пауза / возобновление защиты (расклоакинг/клоакинг файлов и дисков) |

## 🗂️ Структура портативной сборки

```text
StealthGuard/
├── StealthGuard.exe          # Главный исполняемый файл (портативный x64)
├── config.json               # Локальная база правил и настроек
├── emergency_restore.bat     # Автономный батник аварийного восстановления Проводника
├── run.bat                   # Быстрый запуск в обычном режиме
├── run_stealth.bat           # Запуск в скрытом фоновом режиме (--stealth)
└── _internal/                # Автономные зависимости (Qt6, FluentWidgets, Win32)
```

## 🛠️ Аварийное восстановление

Если система аварийно выключилась при активной защите, в портативной папке и в корне репозитория предусмотрен автономный скрипт:
- **`emergency_restore.bat`** — сбрасывает маску `NoDrives`, размонтирует виртуальные диски, возвращает видимость боковой панели Проводника и корректно перезапускает `explorer.exe`.
